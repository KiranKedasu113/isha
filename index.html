Table QR Codes

Each table gets its own QR. Scanning it opens the menu with that table number attached, so when a customer's order comes in (or staff open the link at the counter) you instantly know which table it's for.

One-time setup
  1. Host this file online — e.g. Netlify Drop, GitHub Pages, or Google Sites (all free, a few minutes).
  2. Paste that link below as your base URL.
  3. Set how many tables you have and click Generate — you'll get one QR per table, each tagged automatically.

ℹ️ How QZ Tray Works

  1. Download & Install QZ Tray (v2.2+) on this cashier Windows PC from https://qz.io/download/.
  2. Keep QZ Tray Running in your Windows system tray (near the clock).
  3. Click Connect QZ Tray above. When prompted by QZ Tray, select Allow to grant permission.
  4. Select your USB / Network 80mm thermal printers from the dropdowns above and click Save Printer Preferences.
