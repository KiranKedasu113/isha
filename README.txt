ISHA CAFE - Digital Menu, Billing & Table QR System
=====================================================

WHAT'S IN THIS FILE
--------------------
index.html - the entire app (Customer Menu, Billing/POS, and Table QR
generator). Just one file, no installation needed.

HOW TO USE IT RIGHT NOW (no hosting needed)
--------------------------------------------
Double-click index.html to open it in any browser. You can use the
Billing tab immediately on a laptop/tablet at the counter to build
orders and print bills.

HOW TO MAKE THE QR CODES WORK ON REAL TABLES
----------------------------------------------
A QR code has to point to a live web address, so this file needs to be
hosted online first (free, takes a few minutes):

1. Go to https://app.netlify.com/drop
2. Drag this index.html file onto the page
3. Netlify gives you a live link, e.g. https://isha-cafe.netlify.app
4. Open that link, go to the "QR Code" tab inside the app
5. Paste the link as your base URL, set your number of tables,
   click "Generate All"
6. Click "Print All Table QRs" to get a ready-to-cut sheet of QR
   codes, one per table

Alternative free hosts: GitHub Pages, Google Sites, Vercel.

UPDATING THE MENU OR PRICES
-----------------------------
Open index.html in any text editor (Notepad, TextEdit, VS Code).
Near the top of the <script> section is a list called MENU with every
dish, price, category, and veg/non-veg flag. Edit the numbers/text
there, save, and re-upload to your host.
